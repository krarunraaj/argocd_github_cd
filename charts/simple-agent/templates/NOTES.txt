3. IMPORTANT: `llm.baseUrl` must be an address the POD can reach - this is
   the opposite constraint from banking-web-application's `legacy.serviceUrl`.
   The LLM call happens server-side in this pod, not in the browser. Plain
   "localhost" resolves to the pod itself and will fail; a plain LAN IP that
   only your laptop's browser can see will also fail. Confirm reachability
   directly:

   kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "simple-agent.fullname" . }} -- \
     python -c "import urllib.request;print(urllib.request.urlopen('{{ .Values.llm.baseUrl }}/models', timeout=3).status)"

4. Send a message and confirm you get a real reply back (not a connection
   error) - that's proof the whole chain, chat UI -> API -> Agent -> LLM,
   is wired correctly end to end.
